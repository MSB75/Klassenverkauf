## Optische Optimierung (v1.0.3)

Bei Artikeln ohne Größen füllt der Grundpreisbutton den gesamten Platz der
benachbarten Größenbuttons aus. Produktnamen stehen kartenübergreifend auf
einer Höhe. Der Abschiedsgruß wird ausschließlich über den 🔊-Button auf
dem Abschlussbildschirm gesprochen; der normale Weiter-Button ist stumm.
